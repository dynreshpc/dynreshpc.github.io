## About

The 6th Workshop on Dynamic Resources in HPC (DynResHPC) is a full-day workshop at [ISC 2027](https://isc-hpc.com/).

Dynamic resource management on large-scale HPC platforms is a key component of several past, currently running, and future projects. It poses highly interdisciplinary challenges concerning, among others, the applications that support dynamic resources, extending dynamic resource provisioning to the full system stack, I/O adaptable systems, and I/O scheduling, among others.

This workshop brings together research across the full-stack: runtime adaptive applications that can modify their allocation, system architecture, resource managers, runtime systems, programming models, I/O and storage, and tools. Consequently, computation, communication, and I/O can be coordinated, platforms better utilized, and application makespan reduced. It is organized in connection with the [DynResHPC consortium](/).

## Topics of interest

This workshop is planned to be an amplifier of collaborations around these ideas and covers the following topics (but is not limited to):

- System and system architecture considerations in designing architectures that use dynamic resources
- Emerging software designs to achieve dynamic resource management in high-performance computing
- High-level parallel programming models and programmability techniques to improve applications’ dynamic resource utilization
- Runtime techniques to provide dynamic resource execution models for computation, communication, and I/O
- Resource management frameworks and interfaces supporting dynamic resource management
- Computing and I/O scheduling algorithms providing and/or exploiting static or dynamic resources
- Use of AI and ML techniques to steer dynamic resources in systems and applications
- Ad-hoc storage systems and I/O scheduling techniques supporting dynamic resource provisioning in I/O
- Support for dynamic resource execution of applications in performance, debugging, and correctness tools
- Experiences and use cases applying dynamic resource management to HPC applications
- Experience adopting dynamic resource frameworks
- Performance monitoring and modelling in dynamic environments

## Submission and Publication

Papers must use the two-column LaTeX format with the FGCS templates provided for ISC workshops. All source files must be submitted.

**Paper length** (excluding references):

- Regular papers: 7–10 pages; up to +2 extra pages after review to address reviewer comments
- Short papers: 4–6 pages; up to +1 extra page after review to address reviewer comments
- Papers will be reviewed by at least 3 reviewers.

**Publication:**

- Papers must be **submitted** through the [Linklings ISC submission portal](https://ssl.linklings.net/conferences/isc_hpc/).
- Accepted papers will be published in [Future Generation Computer Systems (Elsevier)](https://www.sciencedirect.com/journal/future-generation-computer-systems) - with worldwide open access for four weeks.

**Templates and guidelines:**

- [FGCS LaTeX templates (zip)](https://isc-hpc.com/wp-content/uploads/2026/08/ISC2027_Workshop-Paper-LaTeX-Templates.zip)
